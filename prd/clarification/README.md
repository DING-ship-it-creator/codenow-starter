# 本地主题引导

## 模块定位

根据本次工作描述和用户补充，逐题检查会影响 MVP 范围的信息缺口。

## 当前已实现

- 按使用者、触发时机、输入、期望结果和例外情况五个固定主题检查。
- 使用简单关键词规则判断描述是否可能覆盖某个主题；用户可补充回答、跳过并编辑整理后的摘要。
- 不调用模型或外部 API，也不要求 API Key；页面会说明关键词规则不具备语义理解能力。
- 入口：`/clarify`。

## 还没做什么

- 关键词规则可能漏判语义，最终信息由用户自行核对和补充。

## 关键决策

- 引导规则和问题在 `lib/local-assistant.ts` 中维护，不发送用户文本。
- 当前标签页 `sessionStorage` 存储会话，不做账号、服务端持久化或云端历史。

## 关联模块

- `intake`：提供工作描述。
- `document`：消费澄清摘要生成 Markdown 方案。
