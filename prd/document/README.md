# 方案生成与导出

## 模块定位

把用户确认过的需求摘要整理成可以继续讨论、编辑和交给 Codex 使用的 Markdown 方案。

## 当前已实现

- 使用浏览器内固定模板，根据原始描述、回答和摘要整理 Markdown 讨论稿；不调用模型或外部 API。
- 用户可修改草稿、标记确认、复制或下载 UTF-8 Markdown 文件。
- 未提供的内容会保留为待补充，页面明确说明草稿不是 AI 分析结果。
- 入口：`/result`，从澄清页的生成操作进入。

## 还没做什么

- 目前整份 Markdown 在一个编辑器内修改，尚非按章节结构化编辑。
- 目前整份 Markdown 在一个编辑器内修改，尚非按章节结构化编辑；剪贴板权限和下载失败尚未端到端验收。
