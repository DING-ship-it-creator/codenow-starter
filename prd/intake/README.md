# 工作描述录入

## 模块定位

帮助用户用日常语言说明一件重复或耗时的工作，并可补充现状、频率、参与者和期望结果。

## 当前已实现

- 首页展示描述输入、字符计数、三条可点击的文字示例和可展开的背景字段。
- 空白内容会被拦截；提交后把描述写入当前标签页会话并进入需求澄清。
- 入口：`/`。

## 用户流程

```text
描述工作 -> 可选补充背景 -> 开始需求梳理 -> 进入 /clarify
```
